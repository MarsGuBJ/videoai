- 文档版本：V1.0

## 1. 引言

### 1.1 编写目的

本文档为视觉大模型平台的功能测试计划，用于指导测试团队开展系统测试工作，明确测试范围、策略、环境、进度、准入准出标准及风险应对，保障平台在交付前达到预期的质量标准。

### 1.2 项目背景

视觉大模型平台提供基于大模型的视频/图片检索（文搜视频、文搜图、图搜图）、轨迹还原、布控告警、任务复核、算法管理、设备接入与实时预览/录像回放等能力，服务于安防监控场景。

### 1.3 参考文档

- 《视觉大模型平台功能操作流程.docx》
- 《docs/mcp-server-interface.md》
- 《docs/person-api.md》
- 《docs/remote-deployment.md》
- 系统前端路由定义（`frontend/src/modules/*/routes.ts`）

## 3. 测试策略

### 3.1 测试类型

| 测试类型 | 说明 | 工具/方法 |
|----------|------|-----------|
| 功能测试 | 依据操作流程逐项验证各模块功能正确性，覆盖正常流、异常流、边界值 | 手工执行 + 测试用例库 |
| 界面测试 | 页面布局、文案、交互反馈、空数据/加载中/失败态展示 | 手工走查 |
| 接口测试 | 前后端接口入参校验、异常码、分页/排序 | Postman / curl |
| 兼容性测试 | 浏览器兼容（Chrome/Edge 最新两个大版本）、常见分辨率（1920×1080、1366×768） | 手工 |
| 性能测试 | 检索响应时间、视频起播时间、事件列表大数据量翻页、资源监控刷新 | 浏览器计时 / JMeter（可选） |
| 安全性测试 | 登录鉴权、越权访问、文件上传类型/大小限制、SQL/XSS 注入基础检查 | 手工 + 拦截代理 |
| 可靠性测试 | 断网/服务重启后的恢复、长时预览稳定性 | 手工 |

### 3.2 用例设计方法

- 等价类划分、边界值分析（时间段、分页、输入长度、上传大小）
- 场景法（端到端业务场景：检索 → 布控 → 事件产生 → 复核 → 统计）
- 错误推测法（非法输入、重复提交、并发操作）

### 3.3 缺陷管理

- 缺陷等级：致命（系统崩溃/数据丢失）、严重（主功能不可用）、一般（功能缺陷有绕行方案）、轻微（界面/文案问题）
- 致命/严重缺陷清零后方可进入验收

## 6. 准入与准出标准

### 6.1 测试准入标准

- 开发自测通过，提测版本可正常部署启动
- 冒烟用例 100% 通过
- 测试环境与测试数据准备就绪

### 6.2 测试准出标准

- 测试用例执行率 100%，通过率 ≥ 95%
- 致命、严重缺陷全部修复并回归通过
- 一般缺陷修复率 ≥ 90%，遗留缺陷均有结论（延期/不修复）
- 测试报告输出并评审通过

## 7. 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 模拟摄像头/视频源不足 | 检索与预览类用例无法充分验证 | 使用 RTSP 推流脚本准备多路循环视频源 |
| 算法服务（Triton）不稳定 | 文搜/图搜结果异常，阻塞测试 | 提前联调；准备降级用例验证异常提示 |
| 第三方云平台不可达 | 云平台同步用例无法执行 | 搭建模拟国标平台或使用预录数据 |
| 需求变更 | 用例失效、返工 | 用例库与需求同步维护，变更后 1 个工作日内更新 |
| 大数据量事件性能未知 | 上线后列表/统计页卡顿 | 准备 10 万级事件数据做性能摸底 |
