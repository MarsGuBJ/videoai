# 视觉大模型平台 测试用例

- 文档版本：V1.2
- 编写日期：2026-09-21
- 参考文档：《视觉大模型平台功能操作流程.docx》
- V1.1 更新说明：适配 2026-09 页面改版——文搜视频结果操作改为页内 tab（以图搜图/快速布防/轨迹图）并新增问答快照操作；文搜图/图搜图移除多选与详情抽屉，结果卡片改为灯箱预览、框选再搜与属性行；轨迹还原增加目标图裁剪与轨迹重置；设备管理新增区域管理弹窗。
- V1.2 更新说明：适配 2026-09 原型改版——万物核（任务管理/复核类型管理）、算法布控（算法管理/版本号管理/布控任务）、视觉事件（事件列表/事件详情/事件统计）、基础配置-事件配置（事件信息/去重/订阅三 tab）按原型重构，相关模块用例整体改写：任务管理改为真接口列表+本地筛选+分页+事件判断上传弹窗；复核类型管理拆分复核类型/定时任务双 tab；算法管理新增统计卡、缺模型标识与版本发布流；布控任务改为真接口列表+区域点位树多选；事件列表状态口径对齐复核结论并新增处置/关闭操作；事件配置新增分页、属性动态行、MQ/HTTP 推送与批量删除。
- 用例编号规则：TC-<模块缩写>-<序号>
- 优先级：P0（核心链路）/ P1（主要功能）/ P2（次要功能/界面）

通用前置条件：测试账号已登录系统；至少一路摄像头已接入并存在历史录像；算法服务与大模型服务运行正常。
