# 模块6 复核类型管理 — 缺陷报告

来源：2026-09-20 对 http://10.10.3.100:5173/reviewTypes 执行模块6用户测试（14 用例，12 通过 / 2 失败）。
测试脚本与证据：`.playwright-cli/module6/`（run_tests.py、shots/、results.json）。

## BUG-FHLX-01 复核类型可重复创建（TC-FHLX-003，P1）

- 现象：已存在某事件的复核类型后，新建弹窗再选同一事件可保存成功，列表出现重复类型；前后端均无唯一性校验。
- 复现：新建复核类型选事件 `face-test` 保存成功 → 再次新建选同一事件 → 仍 toast「复核类型配置已保存」，条数 1→2。
- 根因：`POST /api/review-types` 创建时不查重（backend-lite `review_types.py` create 直接入库）。
- 修复：`app/services/review_types.py` 新增 `assert_review_type_unique()`，创建与更新（名称/编码变更时）均校验唯一，重复返回 409「复核类型「xxx」（code）已存在，请勿重复创建」，前端 toast 直接展示。

## BUG-FHLX-02 删除被引用复核类型未阻止（TC-FHLX-007，P1）

- 现象：复核类型已被定时任务引用，删除仍成功，定时任务残留悬空引用（执行时取不到类型会失败）。
- 复现：给类型建定时任务 → 删除该类型 → toast「已删除复核类型」，定时任务仍在列表。
- 根因：`DELETE /api/review-types/{id}` 不检查 review_schedules / review_tasks 引用。
- 修复：`assert_review_type_not_referenced()` 按 `review_type_id` 检查定时任务、按 `review_type_code` 快照检查复核任务，被引用返回 409「复核类型已被定时任务「xxx」引用，无法删除」/「复核类型已被复核任务引用，无法删除」，与事件配置删除保护（event_infos）行为一致。

## 规格偏差（未改代码，建议产品决策）

- TC-FHLX-004：提示词/备注无长度上限，5000+ 字符静默保存，建议补充长度限制与提示。
- TC-FHLX-009：定时任务周期只有裸 cron 输入框，无「每天/每周」快捷配置，对非技术用户不友好。

## 验证
