## 发现的缺陷（首测发现，均已修复并复测通过）

1. **【P1】新增/编辑云平台缺少 IP、端口格式校验**（TC-YPT-003）：非法 IP `999.999.999.999`、非数字端口 `abc` 均可保存成功。**已修复（2026-09-14）**：前端 `CloudPlatformPanel.vue` `save()` 增加 `isValidIPv4`/`isValidPort` 校验（复用模块11 修复引入的 `frontend/src/utils/regions.ts`）；后端 `CloudPlatformCreateRequest`/`CloudPlatformUpdateRequest` 增加 `@Pattern`（IPv4 + 端口 1-65535）。
2. **【P1】删除云平台无二次确认**（TC-YPT-006）：点击"删除"后立即生效，无确认弹窗。**已修复（2026-09-14）**：`remove()` 增加 `window.confirm("确认删除云平台「名称」？")` 二次确认，取消不删、确认才删。
3. **【P2】云平台删除无引用保护，且设备模型无来源平台字段**（TC-YPT-007）：Camera 模型无"来源云平台"字段，删除接口不检查引用。**已修复（2026-09-14）**：Camera 模型新增 `cloudPlatformId` 字段（数据库 V11/V12 迁移），`CloudPlatformServiceImpl.delete()` 删除前检查引用，被设备引用时返回 409「该平台已被 N 台设备引用，无法删除」。
4. **【P2】云平台无重名/重 Key 唯一性校验**（TC-YPT-008）：同名同 Key 平台可重复创建。**已修复（2026-09-14）**：后端 create/update 增加重名/重 Key 查重，重复返回 409「云平台名称已存在」/「云平台 Key 已存在」，前端 toast 展示该提示。
