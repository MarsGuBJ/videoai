## 发现的缺陷

1. **【P2】上传复核任务无重复提交防护**（TC-RWGL-009）：提交请求进行中「确定」按钮不置灰，双击即创建两条相同任务。**已修复（2026-09-20，待部署复测）**：`App.vue submitReviewTask` 增加 `reviewTaskSubmitting` 防重标志（提交中直接忽略重复提交），`ModalHost.vue` 提交中按钮置灰并显示"提交中…"。
2. **【P2】超大文件拦截提示为 nginx 原始错误页**（TC-RWGL-004）：超过约 20MB 的上传被 nginx 以 413 拒绝，前端把 HTML 错误页原文填入 toast，用户不可读；后端"图片大小不能超过 20MB"提示被 nginx 拦截在前。**已修复（2026-09-20，待部署复测）**：`ModalHost.vue handleReviewImage` 选择文件时前置校验类型与 20MB 大小（超大文件不再发出上传请求）；`api/index.ts extractErrorMessage` 对非 JSON 错误响应不再原样展示，413 统一提示"文件过大，服务器拒绝接收（413）"，HTML 错误页转为"请求失败（状态码）"。
3. **【P3】页面缺少人工复核操作与时间筛选**（TC-RWGL-006/007）：复核结论完全由大模型自动判定，无通过/驳回人工干预入口；筛选仅支持关键字+状态，无时间范围筛选。两项均与用例预期存在差距，需产品确认是否属设计如此（未改动）。
