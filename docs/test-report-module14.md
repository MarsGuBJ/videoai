# 模块14 实时预览 用户测试报告

- 测试范围：docs/test-cases.md「模块14：实时预览（/mediaPreview）」TC-SSYL-001 ~ 017
- 被测服务：http://10.10.3.100:5173/（10.10 现场正式环境，414 台真实摄像头，测试时在线 47~48 台）
- 测试时间：2026-09-14（首测 + 修复后复测）
- 执行方式：Playwright（Chromium headless shell，viewport 1680x950，zh-CN）自动化模拟用户操作，脚本 `.playwright-cli/module14/run_tests.py`，截图证据见 `.playwright-cli/module14/shots/`
- 验证方式说明：实时流走后端代理 `/api/live/{streamName}.live.flv`，现场流多为 H.265/HEVC（FLV CodecID 12，抽样 14 路中 13 路 HEVC）。headless 环境实测 MSE 支持 H.264、**不支持 HEVC**，因此 H.264 设备（1#低压配电室热成像枪机05）为真实渲染验证（videoWidth=1280），HEVC 设备辅以间接证据：页面播放器状态、无报错 toast、直接拉流校验 FLV 头 `464c5601` 且持续有数据。
- 测试数据：场景/收藏均存于浏览器 localStorage（测试用浏览器上下文随跑随弃），测试场景「自动化测试场景-4分屏2路」已在 TC-015 中删除，收藏已在 TC-011 取消；TC-003/008 选中的离线设备被页面自动拉起后已由脚本恢复停止。每轮测试后均核验：设备总数 414、被触碰设备均为 STOPPED，环境无残留改动。

## 回归记录

### 第二轮（2026-09-14 修复后复测）

三个修复项复测结论：

1. **TC-SSYL-004 即时回放真实化 —— 基本生效，有一处残留缺陷**。弹窗改为按当前窗口设备检索最近 N 秒录像并经 `/api/recordings/stream` 起流，VideoPlayer 真实播放，进度计时走动，无占位文案。残留：默认 15 秒窗口下 `search_recordings` 检索不到进行中的录像段（API 直测：15s/30s 窗口返回 0 段，60s 窗口返回 1 段进行中录像），默认档位误报「该设备近期无录像」（→ 缺陷 5，第三轮已修复）。
2. **TC-SSYL-003 离线提示 —— 生效**。toast 文案「设备『×』当前离线，正在尝试拉起…」符合修复说明。
3. **mpegts pageerror —— 未生效**。destroy 改为 pause→unload→detach→延迟 destroy 后，全量回归仍出现 16 次同类 pageerror（→ 第三轮修复）。

其余用例（001/002/005/006/007/009/010/011/012/013/014/015/017）全量回归通过，无回归。

### 第三轮（2026-09-14 二次修复后针对性复测）

针对两个残留问题的专项复测（非全量）：

1. **TC-SSYL-004 即时回放 15s 误报 —— 已修复生效**。`initQuickReplay` 改为固定 30 分钟宽窗口检索 + 覆盖优先/最晚段回退 + 起流 404 按 30s 步长回退重试（最多 90s）。实测：默认 15s 档 8s 内直接起流（进度 00:00→00:03 / 00:15 走动），切 30s/60s 档均 5~6s 起流且总长正确；无录像设备（NVR252通道31，API 确认 0 段）正确提示「该设备近期无录像」未起流；未选窗口提示「当前窗口无视频流」。注：第二轮用作"无录像设备"的 1号低压柔性线枪机02 经 API 复核实际有进行中录像段（18:36~now），第二轮该子用例为巧合通过，本轮已换用 API 确认 0 段的设备重测。脚本 `.playwright-cli/module14/retest_tc004_r3.py`、`retest_tc004_r3_norec.py`，截图 `r3-tc004-*.png`。
2. **mpegts emit 空指针 —— 已修复生效**。根因为 unload() 同步置空 _emitter 而在途微任务随后 emit；修复为同步仅 pause+置 null（token 守卫），pause→unload→detach→destroy 整体延迟 400ms + 元素接管守卫。用前端代理留下的复现脚本 `.playwright-cli/repro-emit-null.py` 回归（4 路上屏 + 8 轮分屏切换 + 反复上下屏）：**pageerror 0 次**（修复前同路径 16 次）；第三轮 TC-004 复测过程中（含多次弹窗 VideoPlayer 起流/卸载）亦为 0 次。

## 发现的缺陷

1. **【P1】即时回放为占位实现，无真实回放画面**（TC-SSYL-004）：~~弹窗内"回放预览"区域为静态演示文案，不随当前选中设备变化，无时间轴。~~ **已修复（2026-09-14）**：即时回放改为按当前窗口设备检索最近 N 秒（15/30/60 可选）录像，经 `/api/recordings/stream` 起流后在弹窗内用 VideoPlayer 真实播放，带「正在回放 mm:ss / 总长」进度；无录像设备提示「该设备近期无录像」，未选窗口提示「当前窗口无视频流」。复测确认生效（残留问题见缺陷 5）。
2. **【P3】播放器销毁后 mpegts.js 抛空指针 pageerror**（TC-016）：`Cannot read properties of null (reading 'emit')`。~~destroy 改为 pause→unload→detachMediaElement→`setTimeout(0)` 延迟 destroy 后，第二轮全量回归仍出现 16 次同类 pageerror。~~ **已修复（2026-09-14，第二轮修复）**：根因为 unload() 同步置空 _emitter 而在途微任务随后 emit；改为同步仅 pause+置 null（token 守卫），pause→unload→detach→destroy 整体延迟 400ms + 元素接管守卫。第三轮用复现脚本 `.playwright-cli/repro-emit-null.py` 回归（4 路上屏 + 8 轮分屏切换 + 反复上下屏）pageerror 0 次。
3. **【建议】离线设备点击无明确提示**（TC-SSYL-003）：**已修复（2026-09-14）**：点击离线设备 toast「设备『×』当前离线，正在尝试拉起…」；DISABLED 设备不上屏并提示已停用（源码 `checkCameraPlayable`，现场无 DISABLED 设备未实测）；自动拉起失败去重提示已实现（本次 25s 观察窗内未触发失败回调，未实测文案）。

## 环境限制与遗留问题

- headless chrome-headless-shell 不支持 HEVC MSE 解码，HEVC 摄像头画面渲染以间接证据验证；建议在装有 HEVC 扩展的 Windows Chrome 上抽查 TC-002/016 的真实画面。
- TC-SSYL-008 需一台**在线且设备端支持 PTZ** 的摄像头补测方向/变倍随动（现场唯一的 ptzEnabled 设备离线且设备端返回 notSupport；历史「1205会议室可控摄像头」已在 2026-09-12 现场清理中停用）。
- TC-016 长时间（10 分钟）16 路并发建议在真实客户端环境补测。
- 场景/收藏/预置点为 localStorage 存储，换浏览器/清缓存后丢失，属产品设计行为，非缺陷。
- TC-016 中 3 路设备（C轴枪机20、人形闸机监控、消防控制室半球02）为自动化拖拽上屏未成功（脚本侧问题，其余 13 路拖拽均成功，产品拖拽功能本身正常）。
